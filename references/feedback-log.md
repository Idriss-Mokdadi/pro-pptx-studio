# Feedback log

Corrections the user asked to keep for **all future presentations**, saved between two versions of the
skill. They apply like house rules. When a new version of the skill is made, merge them into the house rules
of SKILL.md (or taste.md) and empty this list.

How entries get here: after the user corrects something in a deck, ask once whether the change is "only for
this presentation" or "for all future presentations". Only the second answer adds a line here, in the user's
own copy of the skill (`<parent>/pro-pptx-studio/references/feedback-log.md` on their computer); the copy
installed in Claude is read-only. When the user's computer is not reachable, say so and give the line to
add.

Format, one line per correction:
`- YYYY-MM-DD · <the rule, in one sentence> · <where it applies: every deck | defenses | banners | ...>`
